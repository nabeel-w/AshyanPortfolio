# Fonts

Self-hosted through `next/font/local` (`src/app/layout.tsx`), Latin subset only, WOFF2.

| File | Family | Axes | Licence |
|---|---|---|---|
| `instrument-serif-latin-400.woff2` | Instrument Serif (display) | 400 | SIL Open Font License 1.1 |
| `instrument-serif-latin-400-italic.woff2` | Instrument Serif Italic (accents) | 400 | SIL Open Font License 1.1 |
| `geist-latin-var.woff2` | Geist (body) | variable, wght 100–900 | SIL Open Font License 1.1 |
| `jetbrains-mono-latin-var.woff2` | JetBrains Mono (labels, timecode) | variable, wght 400–500 | SIL Open Font License 1.1 |

Source: Google Fonts (fonts.gstatic.com), Latin subset (U+0000–00FF and common punctuation), downloaded 2026-11-11.
To add a weight or subset, download it from the Google Fonts CSS API with a modern browser user agent and add it to `src` in the layout.
